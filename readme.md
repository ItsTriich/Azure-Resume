# Travis's Azure Resume

This is my Cloud Resume Challenge built on Azure. Its a Azure Static Web App, with a visitor counter built on Azure Functions that updates and stores the view count persistantly in a CosmoDB database. The website is built with HTML, CSS, and JavaScript. The visitor counter is built with .NET 8 and Azure Functions.

* Implemented an Azure Static Web App to host the front-end, with a custom domain and SSL/TLS for secure access.
* Developed a serverless back-end with Azure Functions Http Trigger to manage a visitor count feature, integrating it with Azure Cosmos DB for data persistence.
* Automated infrastructure provisioning using Azure Resource Manager (ARM) templates, ensuring consistent and repeatable deployments.
* Established a CI/CD pipeline using GitHub Actions to automate code deployment and testing, maintaining version control and seamless updates.
